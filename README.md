# Shift on the Beach

App web (PWA) de consulta rápida con una síntesis de protocolos de Urgencias (104 protocolos), pensada para la guardia.

- Funciona en iPhone y Android: abrir el enlace una vez con conexión y «Añadir a pantalla de inicio». Después funciona sin internet.
- Herramienta de consulta: verificar siempre dosis y pautas con el protocolo vigente.
